# Salary Management Assessment

Monorepo for a salary management tool built for an HR manager workflow.

## Workspace Layout

- `apps/api`: Express + TypeScript + Prisma backend
- `apps/web`: Next.js + TypeScript frontend
- `docs`: requirements, architecture, tradeoffs, and AI usage notes

## Planned Workflow

This repository is being built incrementally using TDD and clean architecture.

1. Project setup
2. Product and architecture docs
3. Backend tests
4. Backend implementation
5. Salary insights and seed optimization
6. Frontend tests
7. Frontend implementation
8. Final documentation and delivery notes
